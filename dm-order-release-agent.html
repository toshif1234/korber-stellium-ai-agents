The challenge

Releasing by due date alone starves some lines and floods others

Planners release orders that look urgent, only to find a component is short or the work center is already full. Meanwhile, old test orders and stale work in progress cloud the picture.

The Order Release & Dispatch assistant runs a full release cycle in SAP Digital Manufacturing. It allocates stock from a shared pool so two orders never count the same kilogram, checks load against capacity, and ignores stale WIP that would distort the numbers.

Guardrails

Safe to run on production SAP

  • Recommend mode by default. The agent shows the exact release request without sending it.
  • Approve mode for control. Only the orders a supervisor names in chat are released.
  • Auto mode only on request. Used when the run or a scheduled task explicitly says so, one order at a time.
  • Never discards or changes orders. Data-error, stale and held orders are never released.
  • Stops on the first error. If a release fails, the cycle stops and reports the error.
  • Assumptions stated. Capacity source, standard value reading and estimated loads are listed in every run.

FAQ

Frequently asked questions

How does the agent decide which SAP DM orders to release?

It screens orders due in the release window, checks material availability and work-center load, ranks them by due date, priority and open quantity, and releases those that fit within the limits.

Can it release partial quantities?

Yes. If the full quantity would exceed a work-center limit, it tries a partial quantity that fits before holding the order.

What is stale WIP and why does it matter?

Work in progress with no activity for more than 48 hours. The agent counts them separately so old, open jobs do not block new releases.

Does it work with other SAP DM agents?

Yes. It works alongside the DM Supervisor agent for shop-floor monitoring and the Breakdown Recovery agent, which plans recovery when a machine goes down.
